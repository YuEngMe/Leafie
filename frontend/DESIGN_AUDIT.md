### 확인 못 한 것

1. **비밀번호 가림 문자 폭** (14번). 시안 2346:2722는 가려진 값이 84px(16자)이고 앱은 `•`를 쓰는데, `TextField`는 `Text` 위젯이 아니라 `tester.widget<Text>`로 스타일을 못 읽고 렌더 폭도 `EditableText` 내부라 안정적으로 재지 못했다.
2. **아이콘 SVG 모양 대조**. 눈 아이콘(3520:554/3520:572), 종 아이콘(3564:251), 체크박스(2570:2036)는 앱이 `assets/images/*.svg` 또는 `CustomPaint`로 그리는데, 위젯 테스트에서 `SvgPicture`가 실제 픽셀을 그리지 않아 모양 일치를 픽셀로 확인하지 못했다. 크기만 코드 상수와 시안 노드 크기로 대조했다(모두 일치).
3. **3562:196 토스트의 종 아이콘 에셋**. 앱에 대응 요소 자체가 없어 비교 대상이 없다.
4. **`2353:440`의 토스트가 뜨는 정확한 트리거**(내 정보 수정 화면에 머문 채인지, 마이페이지로 돌아간 뒤인지). 시안이 내 정보 수정 화면 위에 얹어 그렸으나 앱은 저장 즉시 pop한다.
5. **그림자 blur 실측**. 카드·버튼 그림자는 코드 상수와 시안 CSS 값을 문자로만 대조했고 렌더 픽셀로 검증하지 않았다.

### 확인 못 한 것

1. **캐릭터·모든 `Image.asset` 높이** — 위젯 테스트에서 PNG가 디코드되지 않아
   `getRect` 높이가 0으로 나온다 (등록1, 등록6, 완료 화면). 폭과 top만 신뢰 가능하다.

   SVG 내부 path의 오렌지 구간을 metadata/code로 읽을 수 없다. 각 프레임 스크린샷
   육안 대조가 필요하다. 앱은 5분할 물결을 CustomPaint로 그리며 step만큼 칠한다.
3. **진행바 물결 모양 자체** — 시안 SVG와 앱 `_WavePainter`의 곡선 형태가 같은지
   못 잼. 앱은 `strokeWidth 6.425` cubic 반원, 시안은 SVG.
4. **날짜 시트 휠 폰트 크기** — 시안은 텍스트 상자 높이(19~22.5)만 있고 fontSize
   토큰이 안 붙어 있다.
5. **말풍선 꼬리 위치·크기** — 2318:3199는 Union boolean-operation이라 꼬리
   좌표를 수치로 못 읽는다. 앱에는 꼬리가 아예 없다.
6. **팔레트 반원 stroke 색·그라디언트** — Ellipse 454(2318:3583)와 완료 화면
   Ellipse 584(2318:4024)가 SVG로 나와 색을 못 읽었다.

8. **구분선 색** (등록7 카드) — 2318:2951/2952가 SVG.

### 확인 못 한 것

1. **캐릭터 PNG 에셋 비교** — 시안 캐릭터는 ChatGPT 생성 PNG(`ChatGPT Image ...`)를 그대로
   쓰는데, 앱은 `PlantCharacterArt` 위젯이다. 테스트에서 `Image.asset`이 실제로 안 그려져
   에셋 픽셀 비교는 못 했다. 모양이 같은지는 육안 확인 필요.
2. **폰트 렌더 폭** — 앱 텍스트 폭(예: "알림" 28.2)은 Flutter 테스트 폰트 기준이라
   Figma raster 폭(29)과 직접 비교하면 오차가 있다. left/top만 신뢰했다.
3. **알림 시각 라벨 좌표** — `_timeLabel`이 `DateTime.now()` 기준이라 값이 매번 달라져
   좌표만 있고 문구는 못 고정했다. 시안엔 시각 표시 자체가 없어 비교 대상 없음.
4. **미구현 화면 5개**(캐릭터 상세 1, 성격, 정보수정 1·2, 꾸미기 2)는 앱에 위젯이 없어
   좌표 측정 자체가 불가능하다. 시안 값만 적었다.
5. **하단 잔디 밴드·구름 배경**의 정확한 색 hex는 `get_design_context`로 뽑지 않았다
   (구조 차이가 압도적이라 우선순위에서 밀림).
